***************
Getting Started
***************

This chapter takes you from a download to a first session.  It says what your computer needs, how to install Umamo and check that the download is the one that was published, what you will see the first time you start it, and where it keeps its settings.  If you already use Live2D Cubism, there is a page that matches what you know to what Umamo calls it.
