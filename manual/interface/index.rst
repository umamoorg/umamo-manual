*********
Interface
*********

This chapter is about the Umamo Editor Window.  The window is divided into areas that each show an editor, grouped into workspaces.  Every action is a command, and a command can be reached from a menu, a shortcut, the command palette, a pie menu, or the right-click menu of an editor.

The editors, such as the 2D Viewport and the Outliner, are described in :doc:`/editors/index`.

The Window
==========

* :doc:`window_system` explains areas: how to split, join, resize, and switch them, and which area the keyboard goes to.
* :doc:`workspaces` covers the tabs along the top, and how to make your own.
* :doc:`menus` lists every row of the four menus.
* :doc:`status_bar` explains the strip at the bottom, its notices, and its progress bar.

Running Commands
================

* :doc:`operation_strip` adjusts the last operation, such as a grab or a mesh generation, after it has run.
* :doc:`command_palette` finds any command by name.
* :doc:`pie_menus` picks from a ring by the direction you move.
* :doc:`keymap` lists the shortcuts, and how to change them.

Your Settings
=============

* :doc:`settings` is the Settings window.
* :doc:`pen_and_touch` records the state of pen and touch input, which is not built yet.
